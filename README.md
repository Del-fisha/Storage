# Домашний Склад - Backend Приложение

## Обзор Проекта

*Домашний Склад* – это надежное и масштабируемое backend приложение, разработанное для управления личным или небольшим 
инвентарем различных бытовых предметов. Оно предоставляет структурированный способ отслеживания товаров по категориям, 
таким как Еда, Химия, Электроника и Мебель, предлагая полноценный CRUD (Создание, Чтение, Обновление, Удаление) API для 
управления данными о предметах.

Проект построен на современном Java с использованием мощного фреймворка Spring Boot, что подчеркивает приверженность 
чистой архитектуре, удобству поддержки и тестируемости. Он демонстрирует глубокие знания ключевых концепций backend 
разработки и лучших практик.

## Используемые Технологии

▷ *Backend Фреймворк:* Spring Boot (3.4.5)

▷ *Язык:* Java (17)

▷ *Внедрение Зависимостей:* Spring IoC

▷ *Веб:* Spring Web (RESFull API)

▷ *Сохранение Данных:* Spring Data JPA, Hibernate

▷ *Драйверы Баз Данных:* PostgresSQL, MySQL, H2

▷ *Управление Схемой Базы Данных:* Liquibase

▷ *Валидация:* Jakarta Bean Validation (JSR 380)

▷ *Логирование:* SLF4J + Logback

▷ *Аспектно-Ориентированное Программирование:* Spring AOP

▷ *Утилитарная Библиотека:* Project Lombok

▷ *Тестирование:* JUnit 5, Mockito, Spring Boot Test, Spring Data JPA Test, Spring WebMvc Test, AssertJ

▷ *Инструмент Сборки:* Apache Maven

▷ Контейнеризация: Docker, Docker Compose

## Ключевые Возможности

▷ *Управление Предметами по Категориям:* Поддерживает различные категории предметов со специфическими атрибутами 
(например, сроки годности для Еды, детали гарантии для Электроники).

▷ *Полные CRUD Операции:* Предоставляет полный набор RESFull эндпоинтов (`GET`, `POST`, `PUT`, `DELETE`) 
для управления предметами внутри каждой категории.

▷ *Валидация Данных:* Реализует надежную проверку входных данных с использованием Jakarta Bean Validation (JSR 380) 
для обеспечения целостности данных. Поддерживаются кастомные сообщения валидации.

▷ *Многослойная Архитектура:* Следует стандартной многослойной архитектуре (Контроллер, Сервис, Репозиторий) 
для четкого разделения зон ответственности.

▷ *Маппинг DTO и Сущностей:* Использует Объекты Передачи Данных (DTO) для обмена данными с клиентами и маппит их в 
JPA Сущности с помощью универсального, переиспользуемого паттерна конвертеров.

▷ *Централизованная Обработка Исключений:* Грамотно обрабатывает ошибки приложения и валидации, возвращая осмысленные 
ответы с ошибками и соответствующими HTTP статусами.

▷ *Аспектно-Ориентированное Логирование:* Реализует AOP для ненавязчивого логирования выполнения методов в слоях 
Сервиса и Контроллера, что помогает в отладке и мониторинге.

▷ *Независимость от СУБД:* Настроено для работы с несколькими базами данных (PostgresSQL, MySQL, H2) с использованием 
Spring Data JPA и Liquibase для управления схемой.

▷ *Готовность к Контейнеризации:* Включает файл `docker-compose.yml` для легкой настройки экземпляра 
базы данных PostgresSQL.

▷ *Комплексное Тестирование:* Характеризуется продуманной стратегией тестирования, охватывающей 
модульные тесты (Сервис, Конвертер) с использованием Mockito и 
интеграционные тесты (Контроллер - `@WebMvcTest`, Репозиторий - `@DataJpaTest` с H2).

▷ *Анализ Покрытия Кода:* Интегрирован с плагином JaCoCo для измерения и отчетности о 
покрытии кода во время процесса сборки.

▷ *Профили Окружения:* Использует Spring Profiles (`dev`, `prod`, `test`) для управления конфигурацией в различных средах развертывания.


## Решаемые Проблемы и Преимущества

Управление личным инвентарем вручную может быть громоздким и подверженным ошибкам. Данное приложение предоставляет 
цифровое, структурированное решение для учета различных предметов дома.

*Для Пользователей:*
▷ Легкое отслеживание разнообразных предметов.
▷ Помогает предотвратить порчу продуктов или забывание о них.
▷ Предоставляет централизованный список вещей.

*Для Бизнеса/Работодателя (Демонстрация Навыков Разработчика):
▷ *Демонстрирует способность создавать надежные API:* Реализация стандартного, хорошо протестированного REST API.

▷ *Владение экосистемой Spring Boot:* Эффективное использование основных модулей Spring (Web, Data JPA, AOP, Validation) 
и внешних библиотек (Lombok, Liquibase).

▷ *Понимание архитектурных паттернов:* Реализация многослойной архитектуры и универсальных базовых классов сокращает 
дублирование кода и улучшает поддерживаемость.

▷ *Сильные практики тестирования:* Комплексные модульные и интеграционные тесты, включая мокирование и 
тестирование базы данных (`@DataJpaTest` с `@DirtiesContext`), обеспечивают надежность и стабильность кода. 
Внимание к изоляции тестов (`@DirtiesContext`) показывает глубокое понимание проблем тестирования баз данных.

▷ *Целостность данных и обработка ошибок:* Реализация валидации и централизованной обработки исключений 
приводит к более надежному и удобному API.

▷ *Гибкость базы данных:* Настроено для нескольких типов баз данных и использует Liquibase, приложение 
адаптируется к различным производственным средам.

▷ *Операционная готовность:* Файл Docker Compose упрощает настройку базы данных, а логирование/профили 
помогают в развертывании и мониторинге.

▷ *Чистый Код и Модульность:* Использование DTO, конвертеров и абстрактных классов приводит к 
высокочитаемому и поддерживаемому коду.

## Как Запустить

1.  *Предварительные требования:*
  * Java 17+
  * Maven
  * Docker и Docker Compose

2. *Настройка Базы Данных (с использованием Docker Compose):*
  ```bash

  docker-compose up -d postgres
  ```
  Это запустит контейнер PostgresSQL на `localhost:5432`. Приложение настроено на подключение к этой базе 
  данных в `application-prod.properties` (при активации `spring.profiles.active=prod`).

3.  *Сборка Приложения:*
  ```bash

  ./mvnw clean install
  ```

4.  *Запуск Приложения:*
  ```bash

  java -jar target/storage-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod
  ```
  (Замените `prod` на `dev` для MySQL или `test` для H2 in-memory базы данных, хотя профиль `test` в основном 
  используется для запуска тестов).

5.  *Документация API:*
  После запуска эндпоинты API будут доступны локально. Возможно, стоит рассмотреть интеграцию OpenAPI (Swagger) 
6. для интерактивной документации.
